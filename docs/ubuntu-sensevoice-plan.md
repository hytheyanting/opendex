# Mac OpenDex + Ubuntu 中文转写试用

用户已选择：在 Mac 试用语音电脑控制，云端视觉模型，密钥由用户在应用中填写；复用已部署的 NetBird SenseVoice 服务。

实现：基于官方 v1.1.14，新分支 feat/ubuntu-sensevoice。在主进程增加 SenseVoice HTTPS 上传及轮询，使用打包的公开私有 CA 验证证书；设置页和引导页增加 provider，默认按键说话、系统语音、中文回复。现有源码将非 ASCII 转写误判为空命令，需要修正为 Unicode 字母/数字识别并验证。

不更改密钥提供方及 API 存储，不读取其他软件密钥。computer 技能试用时启用、保留 Ask；用户亲自授予系统权限。定制版关闭上游自动更新，防止覆盖适配。

步骤：安装锁定依赖与基线类型检查；编写适配器、中文过滤测试及真实 NetBird smoke；实现并运行类型检查/构建；打包和签名本机 arm64 应用，安装到用户 Applications；打开引导，用户填写云模型密钥；验证安全示例任务，必要权限由用户完成后继续。

边界：实际麦克风、云模型调用和鼠标控制必须在用户配置密钥和系统授权后验证，不能用构建成功代替。
