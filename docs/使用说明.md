# OpenDex 中文试用版

用户应用位置：`/Users/air/Applications/OpenDex.app`。

基于官方 v1.1.14 构建，新增 Ubuntu SenseVoice 中文转写。保持 NetBird 已连接。

## 首次配置

1. 在 Language model 步骤选择你拥有 API 密钥的云供应商。密钥直接填在应用内；不要放到聊天、项目文件或终端命令中。
2. CoreHub 请选择 `CoreHub / OpenAI 兼容`，API Base URL 为 `https://openapi.coreshub.cn/v1`，候选模型 `Kimi-K2.5`。该入口使用独立密钥，通过 Chat Completions 调用；实际图片和工具调用能力待填写密钥后验证。也可在 Custom 中填写该服务支持的其他视觉模型。
3. 语音模式使用 Pipeline。Voice input 选择 Push to talk；Transcription 选择 `Ubuntu SenseVoice（中文 · NetBird 内网）`。默认已如此配置。
4. 输出声音选择 System voice，默认优先使用系统中文声音；主题可任选。
5. 在 Settings → Skills & tools 中按需开启 Control the computer，权限保持 Ask。不要为试用设置 Always。
6. macOS“系统设置 → 隐私与安全性”中，亲自授予 OpenDex 麦克风、屏幕录制和辅助功能权限。系统如要求重启应用，再退出重开。

## 试用顺序

先输入文字测试“打开计算器”，确认模型和 Open 技能正常，再用录音按钮或 ⌘⇧Space 说同一句话。语音结束后等待识别和任务授权弹窗。

随后在非敏感测试窗口尝试“把‘你好，这是一条语音控制测试’输入这个文档”，并核对文字。复杂任务留到基础链路确认后。

紧急停止：`⌘Esc`。点击关闭窗口可能仅隐藏到菜单栏；真正退出使用菜单栏 Quit 或 ⌘Q。

Ubuntu 仅识别音频，Mac 上的 OpenDex 才控制桌面。云端视觉模型会接收任务与必要截图；不要把“语音转写在内网”理解成整个链路离线。

## 实现与维护

- 分支：`feat/ubuntu-sensevoice`，源代码目录即本项目。
- 仅使用项目内依赖，不修改系统 Python 或其他应用。
- SenseVoice 通过主进程上传并轮询 `https://100.125.232.11:8787`，使用随包公开 CA 验证 HTTPS，没有禁用证书验证。
- 同一条指令 Allow once 覆盖整套动作，新指令重新询问。
- 定制版关闭上游自动更新，更新时从本 checkout 重新构建。
- 默认关闭匿名统计，使用按键录音及系统语音，默认中文回复。
- 未选用的 Apple 本地模型和 Realtime 云语音未测试。
- 取消命令会忽略过期转写，不会执行；已发往 Ubuntu 的短转写任务可能继续到结束或 60 秒超时。

## 构建与检查

pnpm 使用项目声明的 10.8.1。`.npmrc` 设置 `node-linker=hoisted`，这是 Electron 官方建议的依赖布局，避免打包漏掉传递依赖。

本机 electron-builder 对传递依赖的收集仍出现遗漏，已显式声明锁定版本的 @opentelemetry/api 与 @jimp/custom/plugins/types，并通过实际 app.asar 模块加载检查确认修复。构建时确保 PATH 中的 pnpm 为 10.8.1。

```sh
npm exec --yes --package=pnpm@10.8.1 -- pnpm install --frozen-lockfile
node node_modules/electron/install.js
node --import tsx --test scripts/sensevoice.test.ts scripts/compatible-model.test.ts
node --import tsx scripts/smoke-sensevoice.ts
./node_modules/.bin/tsc --noEmit
./node_modules/.bin/electron-vite build
./node_modules/.bin/electron-builder --mac dir --arm64 --publish never -c.mac.identity=- -c.mac.notarize=false
ELECTRON_RUN_AS_NODE=1 dist/mac-arm64/OpenDex.app/Contents/MacOS/OpenDex scripts/check-packaged.cjs dist/mac-arm64/OpenDex.app
codesign --verify --deep --strict dist/mac-arm64/OpenDex.app
```

此为本机源码构建及本地临时签名，不是上游发布者签名的原版安装包。重建后可能需要重新确认 macOS 权限。

## 正常退出应用工具

新增 `quitApp`，可以说“退出计算器”或“关闭计算器”。由 macOS NSWorkspace 向已运行的应用请求正常退出，不需要截图；应用不存在时不会启动它。应用名通过独立参数并以 `--` 隔离，避免被解释为脚本选项。

复用 Open apps & URLs 的任务授权，不强杀进程。应用等待保存或拒绝退出时会提示仍在运行；仅关一个文档窗口仍需桌面操作。工具禁止退出 OpenDex 与系统桌面组件。

验证：11 项自动检查和类型检查通过；真实计算器正常退出，工具返回 exited，进程退出已核对。轮询中推进 macOS 事件循环，避免运行应用列表缓存造成误报。云模型端到端选用此工具另行验证。
